# 0x14. JavaScript - Web Scraping

This project covers file manipulation, HTTP requests, APIs, JSON data,
and asynchronous programming using Node.js.

## Requirements

- Ubuntu 20.04 LTS
- Node.js 14.x
- Semistandard style
- No use of `var`
- All JavaScript files are executable
- All JavaScript files begin with `#!/usr/bin/node`
- The `request` module is used for HTTP requests

## Files

- `0-readme.js` - Reads and prints a file
- `1-writeme.js` - Writes text to a file
- `2-statuscode.js` - Displays the status code of an HTTP GET request
- `3-starwars_title.js` - Displays a Star Wars movie title
- `4-starwars_count.js` - Counts movies featuring Wedge Antilles
- `5-request_store.js` - Downloads webpage content into a file
- `6-completed_tasks.js` - Counts completed tasks by user
- `100-starwars_characters.js` - Prints Star Wars movie characters
- `101-starwars_characters.js` - Prints characters in API order
